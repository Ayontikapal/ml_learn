# 🏏 IPL Dataset — Data Analysis & Visualization

This folder contains my work with an **IPL (Indian Premier League) dataset**, where I am practicing data analysis, data preprocessing, and visualization using Python.

## 📊 Dataset

The dataset contains IPL-related match and player information that can be explored to identify patterns and trends in the tournament.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔍 What I'm Exploring

Some of the analysis includes:

* Data cleaning and preprocessing
* Handling missing values
* Exploring match statistics
* Team performance
* Player performance
* Runs and wickets
* Match results
* Data visualization
* Identifying patterns and trends in the data
