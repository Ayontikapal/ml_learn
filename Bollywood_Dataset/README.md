# 🎬 Bollywood Movie Data Analysis

This project focuses on exploring and analyzing a Bollywood movie dataset using Python and data analysis libraries. The goal is to understand patterns in movie budgets, box office collections, genres, release dates, audience engagement, and return on investment (ROI).

## 📊 Dataset

The dataset contains information about Bollywood movies, including:

* Movie Name
* Release Date
* Genre
* Budget
* Box Office Collection
* Release Time
* YouTube Views
* YouTube Likes
* YouTube Dislikes

## 🛠️ Technologies Used

* **Python**
* **Pandas** — Data cleaning and analysis
* **NumPy** — Numerical operations
* **Matplotlib** — Data visualization
* **Seaborn** — Statistical visualization
* **Jupyter Notebook**

## 🔍 Analysis Performed

The project includes:

* Data cleaning and preprocessing
* Handling and converting release dates
* Extracting release months
* Analyzing movie budgets
* Comparing budgets with box office collections
* Calculating **Return on Investment (ROI)**
* Finding movies with the highest ROI
* Analyzing average ROI by release time
* Comparing ROI across different genres
* Analyzing YouTube views, likes, and dislikes
* Studying correlations between numerical features
* Creating histograms, box plots, and correlation heatmaps

## 📈 Key Features

### Return on Investment

ROI is calculated using:

```text
ROI = (Box Office Collection - Budget) / Budget
```

This helps measure the profitability of movies relative to their production budget.

### Genre Analysis

The project uses box plots and grouped statistics to compare ROI and audience engagement across different movie genres.

### Audience Engagement

YouTube views, likes, and dislikes are analyzed to understand audience interaction with movie trailers or promotional content.
